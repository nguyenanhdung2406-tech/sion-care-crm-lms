# V1 Workflow

```text
Tạo Thánh đồ
 -> MSSS tự động
 -> Gán KVT
 -> Khảo sát
 -> Baseline
 -> GAP
 -> Việc cần tìm hiểu
 -> Kế hoạch giáo dục
 -> Giao nhiệm vụ
 -> Thực hành / Minh chứng
 -> Đánh giá lại
 -> Baseline mới
 -> GAP mới
```

## Rules

1. Không biết thì không đoán.
2. Chưa đánh giá thì tạo cơ chế để đánh giá.
3. Khảo sát do KVT/caregiver thực hiện.
4. KVT có thể lưu khảo sát khi một phần thông tin còn thiếu.
5. Stage, workflow, quyền hạn, KPI và logic đánh giá là hệ thống khóa.
6. Nội dung giáo dục là nội dung mở.
7. Mọi chỉnh sửa quan trọng phải có audit log trong bản production.
