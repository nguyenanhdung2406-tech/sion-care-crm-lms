# Deploy SION CARE V1

## Vercel
- Import this folder/project.
- Framework preset: Other.
- Build command: none.
- Output directory: `.`

## Netlify
- Drag/drop the project folder, or connect a Git repo.
- Publish directory: `.`

## GitHub Pages
- Push this folder to a repository.
- Enable Pages from the branch root.

## Important
This V1 is a browser-local pilot. Each browser/device has its own data. Do not put real sensitive member data into this build until server authentication, database, storage and access-control policies are connected.
